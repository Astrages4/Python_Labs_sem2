## Лабораторная работа №4. Асинхронный исполнитель задач

# Цель работы:
Научиться реализовывать приложения с асинхронной моделью управления

# Постановка задачи:
Реализовать асинхронный исполнитель задач, обрабатывающий задачи из
очереди с использованием расширяемых обработчиков.

# Функциональные требования:
- асинхронная очередь задач;
- описание контракта обработчика через Protocol ;
- использование контекстных менеджеров для управления ресурсами;
- централизованное логирование и обработка ошибок;

# Технические требования:
- корректное использование async / await ;
- отсутствие блокирующих операций в event loop;
- архитектура, допускающая добавление новых типов задач и обработчиков;
- аннотации типов и документация;

# Ожидаемый результат:
Рабочая асинхронная система обработки задач, демонстрирующая архитектурную целостность и корректное использование механизмов Python.
